# Expense Tracker

## Overview:

This is a Python-based program designed to help multiple users track finances such as income, savings, and expenses. The project includes 2 formats for both terminal based version and Jupyter Notebook Version for visualization.
- **First time users get to register and data is stored in SQL database for future access.**
- **Registered users enter their login credentials securely with unique authentication (For instance, username) to add finances, view account summary, and visualize spending habits through interactive charts.**


## Features:
1. **User Authentication**:
   Each User create an account with unique credentials (username, password) and personal information. Upon registeration, users are assigned unique IDs for effective programming and storage.
2. **Income, Savings, & Expense Tracking**:
   User actions include adding expenses in form of category, updating income, and saving from income.
3. **Data Storage**:
   Data storage transition from CSV to SQL for efficient management.
4. **Visualizations**:
   Financial data can be viewed in form of Pie Charts and Bar Charts.

## Software:
1. **Python**: Core
2. **SQLite**: Users data management
3. **Panda & Matplotlib**: Data analysis and visualization in Jupyter Notebook

## Installation & Setup:
1. **Terminal-based**:
   ```bash
   python xpense3.py
   ```
2. **Jupyter Notebook**:
   ```bash
   jupyter notebook
   ```

## Usage:
- **Register/Login**
- **Add Income**
- **Add Savings**
- **Add Expense**
- **View Account Summary**
- **Visualize data**
